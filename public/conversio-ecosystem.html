Secção 2

Fluxos de Automação End-to-End

Três pipelines de produção que transformam automaticamente um estranho num cliente fidelizado, sem intervenção humana.

Pipeline Conversacional

Da mensagem recebida no WhatsApp à resposta gerada por IA com memória de longo prazo em menos de 35 segundos.

1

Mensagem Recebida — Evolution API

O utilizador envia uma mensagem para o número WhatsApp da Conversio. A Evolution API recebe e reencaminha para o backend.

POST /api/webhooks/whatsapp → { remoteJid, pushName, messageText, instanceName }
2

Pentagon Agent — Router Anti-Ban

Recebe o payload, verifica duplicatas por ID de mensagem, adiciona à fila da instância e aplica delay humanizado de 8 a 35 segundos. Simula "a digitar..." via Evolution API.

Verifica duplicatas via Set<msgId>
Bloqueia instância com instanceLock Map em memória
Pausa nocturna automática: 23h–07h Angola
3

WhatsApp Lead Agent — SDR com Memória

Verifica se é utilizador registado. Cria/actualiza lead em whatsapp_leads. Consulta memória longa (20 factos) + histórico (últimas 15 msgs). Chama GPT-4o com contexto completo.

Se agent_active = false → silencia IA (modo humano)
Memória persistente: tabela whatsapp_memory
4

Resposta Enviada + Memória Actualizada

Resposta gerada pelo GPT-4o enviada via Evolution API. Log gravado em whatsapp_messages. Lead score e status actualizados em whatsapp_leads.

Pipeline de Lifecycle — D0 a D+10

Sequência automática desde o registo até à conversão ou churn, com handoff inteligente entre agentes.

D0

Registo do Utilizador

Novo utilizador criado na plataforma. Welcome Agent dispara mensagem de boas-vindas no WhatsApp às 08:00 do dia seguinte.

D+1

Activation Agent — 09:00

Envia vídeo demonstrativo e convida o utilizador a criar o primeiro anúncio. Regista evento em agent_logs.

D+3

Conversion Agent — 10:00

Envia casos de sucesso reais de clientes angolanos com CTA directo para upgrade.

D+5

Urgency Agent — 11:00

Oferta limitada com prazo. Reforça a proposta de valor do plano profissional.

D+10

Retention Agent — Última Tentativa

Mensagem pessoal de última hipótese + alerta imediato ao Admin no WhatsApp sobre o utilizador em risco.

SE converte → Post-Sale Agent activa sequência pós-compra
SE não converte → Recovery Agent avalia risco de churn

Pipeline de Marketing Autónomo

Do diagnóstico estratégico automático ao envio segmentado com A/B testing — sem intervenção humana obrigatória.

1

Smart Orchestrator — Diagnóstico (cada 6h)

Analisa métricas do sistema: leads frios, risco de churn, taxa de conversão, campanhas activas. Deteta oportunidades.

INPUT: users, whatsapp_leads, transactions, generations, campaigns
2

Plano de Acção Criado

Registo inserido em orchestrator_action_plans. Notificação enviada ao Admin via WhatsApp. Admin aprova (ou plano de baixa prioridade é auto-aprovado).

3

Campaigns Agent — Segmentação

buildAudience() filtra utilizadores por segmento dinâmico. Insere destinatários em campaign_recipients com priorização.

Segmentos: new_users, churn_risk, vip_customers, ready_for_upgrade...
Regras dinâmicas: score, temperatura, inactividade, plano
4

Campaigns Agent — Envio em Lotes (cada 10min)

Processa até 100 destinatários por ciclo. A/B testing: alterna variant_a e variant_b a cada envio. Respeita janela 08h–22h Angola. Cooldown de 48h por utilizador.

5

Central Orchestrator — Despacho Final

Processa agent_tasks a cada 5 minutos. Executa sendWhatsAppMessage(). Regista em crm_interactions. Actualiza campaign_stats em tempo real.
